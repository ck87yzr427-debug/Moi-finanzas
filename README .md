# Moi Finanzas PWA v2

Esta versión ya está preparada como PWA instalable.

## Incluye
- Proyectos y trabajos.
- Ingresos y gastos asociados por proyecto.
- Beneficio real y margen.
- Control semanal por categoría.
- Cálculo de desplazamientos: km, consumo, precio del combustible y desgaste opcional.
- Beneficio previsto al preparar un presupuesto.
- Funcionamiento offline mediante Service Worker.
- Almacenamiento local con IndexedDB.
- Copia de seguridad JSON y exportación CSV.
- Iconos para iPhone/iPad y Android.
- No conecta con bancos.

## Importante
No basta con abrir `index.html` desde Archivos del iPhone. Para instalar una PWA,
debe servirse desde una web HTTPS.

## Instalación en iPhone/iPad
1. Publica esta carpeta en un hosting HTTPS.
2. Abre la URL en Safari.
3. Pulsa Compartir.
4. Pulsa “Añadir a pantalla de inicio”.
5. Abre “Moi Finanzas” desde el icono creado.

## Hosting gratuito recomendado
Puedes publicar la carpeta en GitHub Pages, Netlify o Cloudflare Pages.
